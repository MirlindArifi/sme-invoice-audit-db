# SME Invoice Audit DB — Municipal Procurement & Tax Compliance Auditor

## Overview
A relational database and analytical SQL audit system designed for municipal internal auditors and financial controllers. The project models an audit workflow that reviews supplier invoices submitted against municipal procurement awards, enforcing relational integrity and detecting billing anomalies and statutory VAT discrepancies under Kosovo Law No. 05/L-037.

- Status: Initial repository setup complete; schema design in progress.
